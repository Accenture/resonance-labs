# @orchestra/resonance-metadata

Curated Labs alignment metadata generated by the Resonance Labs build pipeline.

Consumed by Conductor for component health dashboards, coverage summaries, and example linking.

## Contents

| File | Purpose |
|------|---------|
| `dist/component-summary.json` | Per-component Labs alignment metrics |
| `dist/examples.json` | Labs example pages per component |
| `dist/coverage-summary.json` | Portfolio-level alignment dashboard data |
| `dist/criterion-map.json` | Criterion-level status per component |

## Usage

```js
import { componentSummary, coverageSummary } from '@orchestra/resonance-metadata';

// or import individual files
import summary from '@orchestra/resonance-metadata/component-summary';
import examples from '@orchestra/resonance-metadata/examples';
```

## Notes

- Raw `labs.manifest.json` files are **not** included. This package contains only curated output.
- Regenerated on every `npm run build` in the Resonance Labs repo.
- `labsAlignment` is calculated as `round((implemented + partial * 0.5) / specCount * 100)`.
